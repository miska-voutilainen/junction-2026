# Agent instructions (all AI assistants)

[CLAUDE.md](CLAUDE.md) is the entry point for every coding assistant on this project (Claude Code, Cursor, Codex, Gemini, Copilot and others), and [docs/spec.md](docs/spec.md) says what to build. Read both, then the rules in `.claude/rules/` (all of them; `design.md` for UI files and `testing.md` for tests matter most when you touch those).

"go" means: follow `.claude/skills/go/SKILL.md`. The other workflows are in `.claude/skills/` (`ship-pr`, `handover`, `polish-pass`, `demo-prep`, `kickoff`). Subagent definitions are in `.claude/agents/`; without subagent support, run their checklists yourself as separate passes.

Your lane is `LANE` in `.claude/settings.local.json`, written by the `join` skill (`.claude/skills/join/SKILL.md`); on a new machine, follow it first. Without Claude Code's hooks, run the briefing yourself at session start (`node .claude/hooks/session-brief.mjs`) and follow the guard's rules by hand: never read `.env`; never force push or push to `main`; never `rm -rf` outside the repo; don't edit another lane's or shared files (`README.md`, `CLAUDE.md`, `AGENTS.md`, `docs/` except `docs/spec.md` are open to all lanes); no stray root files; GitHub text through `--body-file`, starting with `[agent:<lane>]`; no emoji in commit messages or PRs, no `Co-Authored-By` trailer naming an AI and no "Generated with" boilerplate; every PR body has the template's AI use section; never touch issue #1 except to comment; never change anything in `.claude/` (except your own `settings.local.json`) without the team's agreement. Find code through the Graphify map before searching (`.claude/rules/tools.md`). Run lint, typecheck and tests before saying a change is done.
